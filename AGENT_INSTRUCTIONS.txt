1. PROJEKTO APRAŠYMAS (KAS TAI PER PROGRAMA?)
================================================================================
„PrintReady PRO“ – tai profesionali gamybinė UV spaudos failų paruošimo, apkirpimo
ir „Hotfolderių“ stebėjimo sistema, sukurta „Podbase“ gamybos linijai.

PAGRINDINĖS FUNKCIJOS:
1. Automatizuotas spaudos failų apkirpimas pagal MacBook bei kitų produktų .PNG kontūrus.
2. Spalvų konvertavimas iš RGB į CMYK su oficialiu „U.S. Web Coated (SWOP) v2“ ICC profiliu.
3. 6-ojo „Spot White (W)“ balto rašalo pagrindo kanalo sugeneravimas su 1 px sutraukimu
   (choke) ir 5% tankumu (solidity) pagal griežtus „ColorGATE RIP“ ir „Photoshop“ reikalavimus.
4. Dvigubas Hotfolderių skenavimas:
   - Standartiniai užsakymai automatiškai išsaugomi į READY aplanką.
   - Brokai / Rejects automatiškai nukreipiami į READY\BROKAI aplanką.
5. Fono stebėjimo servisas (real-time background watcher).
6. Integruotas „GitHub Releases“ automatinių atnaujinimų modulis su iššokančiu langu (Popup).
7. Windows 11 Fluent Design tamsusis režimas (Dark Mode) su „PySide6“ ir „QFluentWidgets“.

================================================================================
2. KAIP PARSISIŲSTI PROJEKTĄ IŠ GITHUB IR PASIRUOŠTI APLINKĄ
================================================================================
Repozitorijos URL: https://github.com/lkuprys/PrintReady.git

ŽINGSNIAI NAUJAME KOMPIUTERYJE:
1. Atsidaryti terminalą (PowerShell / CMD) ir nuklonuoti kodą:
   git clone https://github.com/lkuprys/PrintReady.git
   cd PrintReady

2. Įdiegti reikalingas Python (3.10+) bibliotekas:
   pip install -r requirements.txt

   Priklausomybės faile `requirements.txt`:
   - PySide6>=6.6.0
   - PySide6-Fluent-Widgets[full]>=1.5.0
   - Pillow>=10.0.0
   - tifffile>=2024.1.1
   - imagecodecs>=2024.1.1
   - scipy>=1.11.0
   - numpy>=1.26.0
   - pywin32>=306

3. Programos paleidimas iš kodo:
   python main.py
   (arba: python fluent_gui.py)

4. Standalone Windows .exe kompiliavimas:
   Paleiskite `build_exe.bat` (arba per PyInstaller sukompiliuokite dist/PrintReady.exe).

4. GRIEŽTI TECHNINIAI UV SPAUDOS REIKALAVIMAI (ColorGATE & Photoshop)
================================================================================
⚠️ ŠIŲ PARAMETRŲ NEGALI KEISTI AR SUGADINTI JOKIE ATNAUJINIMAI:
- Formatas: 6 kanalų TIFF (C, M, Y, K, Alpha/Transparency, Spot White W).
- Rezoliucija: 300 DPI.
- Tag 34675 (InterColorProfile): Privalo turėti įterptą „U.S. Web Coated (SWOP) v2“ profilį.
- Tag 34377 (Photoshop 8BIM): Privalo turėti resursus:
  - 1005: ResolutionInfo (300 DPI)
  - 1006 / 1045: Alpha Channel Names („Transparency“, „W“)
  - 1050: Spot Channel Solidity = 5%, Color Space = CMYK (0, 0, 0, 0)
- Baltas rašalas (Spot W): Sugeneruojamas iš kontūro kaukės su 1 px vidiniu sutraukimu (choke),
  kad po spaudos neliktų balto kraštelio.

6. SVARBŪS PROGRAMAVIMO IR INŽINERINIAI PRINCIPAI
================================================================================
1. WINDOWS CONSOLE KODAVIMAS (cp1257):
   Windows aplinkoje tiesioginis `print("🔍 ...")` iššaukia `UnicodeEncodeError`.
   Visada naudokite saugų išvedimą (pvz., `sys.stdout.encoding` su `errors='replace'`).

2. UI KONTRASTAS (QFluentWidgets Dark Theme):
   Visos kortelės (`CardWidget`, `SimpleCardWidget`) ir etiketės privalo turėti
   aiškius stilius: fonas tamsiai pilkas (`#1E293B`), tekstas šviesus (`#F8FAFC`),
   kad niekada neatsirastų baltas tekstas ant šviesaus fono.

3. ŠVARUS KODAS IR GIT:
   Niekada nerašykite AI autorystės žymių ar komentaruose minimų modelių vardų.
   Kodas turi atrodyti kaip aukščiausio lygio profesionalių programuotojų rankomis rašytas produktas.
